Alertas activas

Se comprueban las rutas Host de Traefik con GET /. HTTP considera sanas respuestas 2xx/3xx; timeout predeterminado 5 s. Los certificados TLS avisan 14 días antes. El disco corresponde al filesystem visible para el panel. Sin email ni webhooks.

    El panel comprueba Docker, Swarm, servicios, redes, PostgreSQL y respaldos. Para detalles del sistema operativo, disco y puertos, ejecuta sudo vps-manager-diagnostics por SSH.

    Actualizaciones de VPS Manager

    Versión instalada: —

    No hay una actualización web en curso.

    Usar el comando SSH manual
    sudo vps-manager-update

    La actualización web solicita una tarea fija al servicio host de systemd; no permite enviar comandos ni versiones y no concede acceso Docker de escritura al panel. También puedes ejecutarla manualmente por SSH.
